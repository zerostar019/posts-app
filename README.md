# Posts

Список постов из JSONPlaceholder + создание поста через Server Action.

Демо: https://posts.135.106.195.70.sslip.io

Next.js 16 (App Router), TypeScript, Tailwind, Zod.

## Запуск

```bash
npm install
npm run dev
```

Тесты и проверки: `npm test`, `npm run typecheck`, `npm run lint`.

Docker: `docker compose up -d --build`

## Коротко о реализации

- Список — Server Component, ответ API кэшируется на 5 минут, пагинация через `?page=`.
- Форма — Server Action + `useActionState`, валидация Zod на сервере.
- JSONPlaceholder ничего не сохраняет, поэтому созданные посты пишу в `data/posts.json`. Переживают перезапуск, в Docker лежат в volume. Для прода взял бы БД.

## AI

С помощью AI (Claude Code) сгенерированы: Zod-схемы, Server Action, компоненты и вёрстка, сохранение в файл, тесты, Dockerfile.

Как проверял:

- сверял API с [документацией Next.js 16](https://nextjs.org/docs) — нашёл, что в `error.tsx` проп теперь `retry`, а не `reset`;
- проверил, что Zod используется в синтаксисе v4;
- typecheck, lint, build и тесты (8 шт.: валидация формы и запись в файл, включая параллельные запросы);
- руками:
  - ошибки формы по каждому полю, введённый текст не теряется;
  - создание поста, пост остаётся после перезапуска сервера;
  - форма работает с выключенным JS;
  - обход select (`userId=42` напрямую в запросе) — сервер отклоняет;
  - границы длины: текст на 2000 символов проходит, на 2001 — нет;
  - `<script>` в заголовке выводится как текст;
  - вёрстка на 375px, светлая и тёмная тема. Тут нашёл баг: длинное слово без пробелов растягивало страницу — добавил `wrap-anywhere`;
  - кривые `?page=abc`, `?page=999`.
